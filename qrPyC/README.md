# Príncipe & Centauro · Tarjeta digital

Tarjeta digital con el ecosistema de PyC: Instagram, Facebook y sitio web.

- `index.html` – la tarjeta
- `styles.css` – diseño (negro + dorado)
- `script.js` – botón "Compartir tarjeta" y efectos

## Publicar (gratis)

1. Entrar a <https://app.netlify.com/drop> y arrastrar esta carpeta.
2. En *Site configuration → Change site name* poner `principeycentauro`
   → `https://principeycentauro.netlify.app`
3. Con esa URL se genera el QR para la presentación.

Para cambiar o sumar una red, editar los links en `index.html`.
